## Contexto de Ejecución
- Cliente: Opticolor
- Desarrollador: VisioFlow Tech
- Stack: Next.js (App Router), Azure SQL Server (MSSQL), Tailwind v4, Shadcn UI, Recharts.

Al trabajar en este proyecto, tienes prohibido programar de forma libre o intuitiva. Siempre debes actuar bajo la estricta supervisión de la flota de agentes especializada definida en `/agents/` y estructurar tus diagnósticos y bloques de código quirúrgico bajo la metodología obligatoria que cada agente exige.
