# Opticolor Project — Agent Operating System

## Next.js & Tailwind v4 Environment
Este proyecto está construido sobre Next.js 14+ con arquitectura de App Router (Server Actions y React Suspense) junto con Tailwind v4 (estilos basados en variables CSS nativas y OKLCH). Ignora patrones obsoletos de Pages Router y clases fijas utilitarias de color. Toda refactorización de código debe pasar de forma limpia la verificación estricta de tipos de TypeScript.

## 🚀 Specialized Agent Fleet
Este proyecto cuenta con un sistema coordinado de agentes élite bajo el **OMNI-AGENT PROTOCOL**.
